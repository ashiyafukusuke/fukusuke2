# Antigravity用プロンプト（写真差し替え）

トップページの写真を3枚差し替えます。素材は `update-20261103` フォルダにあります。

1. `update-20261103/public/images/` の3ファイル（hero-pc.jpg、reason-01.jpg、owner.jpg）で、`public/images/` の同名ファイルを上書きする
2. 理由01の写真の alt を「指の関節にタコのある施術者の手が、足を包み込むように押している」に変える
3. 店主セクションの写真の alt を「足を揉む店主 福助」に変え、表示位置（object-position）を `72% 22%` にする（顔が切れないように）
4. PCのヒーロー写真の表示位置（object-position）を `62% 40%` にする
5. 文面・レイアウト・ほかの写真は変えない
6. build を通し、幅375px と 1280px で、ヒーローと店主の写真で顔や手元が切れていないかを確認する
7. 作業が終わったら `update-20261103` フォルダは削除し、コミットに含めない

画像のキャッシュが残る場合は、ファイル名にバージョンを付ける（例：hero-pc.v2.jpg）か、next/image の設定に従って更新が反映されるようにする。
